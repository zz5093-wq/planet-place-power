# SOCS-SHU 289 · Portfolio template

Planet, Place, and Power — NYU Shanghai, Fall 2026.

A starting point for your course portfolio. Click **Use this template**, name your
copy `planet-place-power`, keep it **Public**, then switch on GitHub Pages under
Settings → Pages (deploy from `main` / `root`).

Full instructions, including troubleshooting, are in **Build your portfolio site**
on Brightspace.

```
index.html              your front page — name, site, one card per journal entry
style.css               every colour and size; the block at the top controls them all
journal/week-01.html    one journal entry, laid out as the six required sections
.nojekyll               tells GitHub to publish the files as written — do not delete
```

**House rule:** no external fonts, scripts, or CDN links. Everything loads from this
repository, so the site behaves the same on campus in Shanghai as anywhere else.
